# etolegko-test

Консольный скрипт измеряет скорость скачивания по HTTP или HTTPS.

## Подготовка

Требуется Node.js 24 или новее и Corepack.
Версия Yarn закреплена в `package.json`.

```sh
corepack enable
yarn install
```

## Запуск

```sh
yarn dev https://example.com/image.jpg
# или
yarn build
yarn start https://example.com/image.jpg
```

Подставьте адрес своего файла. Скрипт скачает его 10 раз подряд.
Время каждого запроса измеряется до конца чтения тела ответа.
Скрипт выводит среднее время запроса, общий объём скачанных данных и скорость.
Для объёма и скорости он подбирает единицы отдельно по десятичной шкале. Например,
12 000 КБ отображаются как 12 МБ, а 500 000 байт в секунду — как 500 КБ/с.
Скорость равна общему объёму, делённому на суммарное время запросов.

## Команды

- `yarn run-dev-server` — запуск локального HTTP-сервера. Он выводит свой адрес и отдаёт 1 МБ на каждый запрос. Для проверки оставьте сервер запущенным и выполните в другом терминале:

  ```sh
  yarn build
  yarn start http://127.0.0.1:3000/
  ```

  После 10 запросов счётчик покажет 10 МБ. Чтобы остановить сервер, нажмите Ctrl+C в его терминале.

- `yarn dev <URL>` — запуск `src/index.ts`.
- `yarn typecheck` — проверка типов без сборки.
- `yarn test` — запуск тестов Vitest.
- `yarn build` — сборка в `dist/`.
- `yarn start <URL>` — запуск собранного проекта после `yarn build`.
